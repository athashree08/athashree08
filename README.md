## Featured Projects

### RULVision — Predictive Maintenance & RUL Prediction

**BiLSTM · Conv1D · XGBoost · SHAP · FastAPI · NASA C-MAPSS**

An ISO 13374-based predictive maintenance system for estimating the Remaining Useful Life of turbofan engines.

* Built a temporal deep-learning pipeline using **Conv1D + BiLSTM**
* Developed an **XGBoost regression** model as a complementary architecture
* Combined predictions using a weighted ensemble
* Achieved **13.63-cycle RMSE** with the standalone BiLSTM
* Integrated **SHAP** for sensor-level prediction explanations
* Built a FastAPI backend for ML inference and fleet monitoring

[View Project →](https://github.com/athashree08/ISO-13374-based-Predictive-Maintainance)
